# 中国纯净日历 · webcal 订阅

仅含单一内容、互不干扰的三份 iCalendar 日历，可订阅到苹果日历（及支持 webcal 的客户端），按周期自动更新。每份日历有独立图标与主题色，便于一眼区分。

## 订阅链接（webcal）

- **🍃 24 节气（纯净版）**：`webcal://477910067.github.io/calendar-webcal/solar-terms.ics`
  - 2024–2050，共 648 条，完整 24 节气（含清明），无节假日 / 农历 / 黄历；图标 🍃、绿色主题
- **🧨 法定节假日及调休（纯净版）**：`webcal://477910067.github.io/calendar-webcal/holidays.ics`
  - 2024–2026，共 41 条事件（放假区间 22 + 调休补班 19），无节气 / 农历 / 黄历；图标 🧨、红色主题
  - 显示规则：连续法定节假日合并为**单条区间事件**并标注 **「XX(休)」**（如中秋显示为 9/25–9/27 的「🧨 中秋(休)」）；调休补班显示为 **「XX(班)」**（如 🧨 国庆节(班)）
- **⭐ 民俗节及纪念日（纯净版）**：`webcal://477910067.github.io/calendar-webcal/folk.ics`（新增）
  - 2024–2035，共 336 事件；图标 ⭐、金色主题
  - 农历民俗：元宵、龙抬头、七夕、中元、重阳、寒衣、腊八、小年、除夕
  - 公历纪念日：情人节、妇女节、植树节、青年节、儿童节、建党节、香港回归纪念日、建军节、教师节、万圣节、记者节、双十一、澳门回归纪念日、平安夜、圣诞节
  - 移动节日：母亲节（5 月第 2 周日）、父亲节（6 月第 3 周日）、感恩节（11 月第 4 周四）
  - 不含法定节假日与 24 节气，保持纯净

**图标 / 配色**：iCalendar 标准不支持给单个事件设图片图标，本仓库用「标题前缀 emoji」实现跨客户端可见的图标（🍃 / 🧨 / ⭐），并为每个日历设置了主题色（`COLOR` 属性，订阅时客户端会作为默认色）。如某客户端未生效，可在日历 App 里手动给对应订阅改个颜色。

## 如何订阅

- **Mac 日历**：文件 → 新建日历订阅 → 粘贴上面的 `webcal://` 链接；或直接打开 `index.html` 点链接。
- **iPhone / iPad**：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历 → 粘贴链接（⚠️ 复制链接后用 Safari 打开，微信 / QQ 内置浏览器会拦截）。

订阅后客户端会定期自动拉取；更新 `.ics` 后无需手动重导。

## 文件说明

| 文件 | 作用 |
|---|---|
| `solar-terms.ics` | 24 节气，天文算法按北京时间交节，覆盖至 2050 年；图标 🍃 |
| `holidays.ics` | 法定节假日 + 调休补班，数据来自 chinese-days（同步国务院公布安排）；连续节假日合并为区间并标注「(休)」、补班标注「(班)」；图标 🧨 |
| `folk.ics` | 民俗节及纪念日，农历节日用 lunar-javascript 推算、公历纪念日按规则计算；图标 ⭐ |
| `gen_solar.py` | 24 节气 `.ics` 生成脚本（纯 Python，无依赖）。重生成：`python3 gen_solar.py solar-terms.ics` |
| `gen_holidays.cjs` | 节假日 `.ics` 生成脚本（依赖 `chinese-days`）。更新数据时：`npm i chinese-days` 后 `NODE_PATH=node_modules node gen_holidays.cjs holidays.ics` |
| `gen_folk.cjs` | 民俗节 `.ics` 生成脚本（依赖 `lunar-javascript`）。重生成：`npm i lunar-javascript` 后 `NODE_PATH=node_modules node gen_folk.cjs folk.ics` |
| `server.py` | 零依赖本地 webcal 服务（仅绑定 `127.0.0.1:8123`）。需内网 / 离线使用时，在目录下 `python3 server.py`，再订阅 `webcal://127.0.0.1:8123/xxx.ics`（仅本机可见） |
| `index.html` | 订阅说明页 |

## 更新

- 节假日数据依赖国务院年度安排，2027 年及以后待发布后更新 `holidays.ics` 并重新推送。
- 24 节气已覆盖至 2050 年，一般无需更新。

## 数据来源与免责

- 节气：天文公式推算（北京时间）。
- 节假日：`chinese-days` 项目（国务院公布数据）。
- 仅供参考，请以官方发布为准。
