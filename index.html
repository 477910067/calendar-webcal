怎么订阅（公网链接，任意设备可用）

  1. Mac 日历：文件 → 新建日历订阅 → 粘贴上面的 webcal://… 链接；或直接点页面上的链接。
  2. iPhone / iPad：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历 → 粘贴链接。
    （⚠️ 复制链接后需用 Safari 打开，微信/QQ 内置浏览器会拦截）
  3. 订阅后日历会定期自动拉取；我更新 .ics 内容后无需你手动操作即可同步。

自托管（可选）

公网版已满足绝大多数需求。如需在内网 / 离线环境使用，仓库内 server.py 是一个零依赖的本地 webcal 服务：在目录下运行 python3 server.py，然后订阅 webcal://127.0.0.1:8123/solar-terms.ics 等同目录链接即可（仅本机可见）。
