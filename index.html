苹果日历（macOS/iOS）订阅不支持用 PNG/图标文件给事件设形状图标——但可把 emoji 作为标题首字符让苹果用它替换事件左侧圆点（仅首字符生效，后缀不生效）。
订阅时给每份日历选不同颜色（如节气绿、节假日红、民俗紫）即可实现三类视觉区分；镂空图标 PNG（树叶/鞭炮/星星）已托管但苹果日历不读取，订阅模式下无法自动套用。
当前版本事件名已带 emoji 后缀，例如 小寒 🍃 / 元旦(休) 🧨 / 腊八节 ⭐。注意：苹果日历仅用标题首字符的 emoji 替换事件左侧圆点，后缀 emoji 只在文字末尾显示、不会改变左侧图标形状；若要在左侧显示形状图标需改用前缀 emoji（你此前未采用）。

怎么订阅（公网链接，任意设备可用）

  1. Mac 日历：文件 → 新建日历订阅 → 粘贴 webcal://… 链接；或直接点页面上的链接。订阅时可给每份选颜色。
  2. iPhone / iPad：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历 → 粘贴链接。
    （⚠️ 需用 Safari 打开，微信/QQ 内置浏览器会拦截）
  3. 订阅后日历会定期自动拉取；我更新 .ics 内容后无需手动操作即可同步。

自托管（可选）

公网版已满足绝大多数需求。如需在内网 / 离线环境使用，仓库内 server.py 是一个零依赖的本地 webcal 服务：在目录下运行 python3 server.py，然后订阅 webcal://127.0.0.1:8123/solar-terms.ics 等同目录链接即可（仅本机可见）。
